---
name: Public package brochure
description: Product decision for downloadable package brochures generated from the package detail page
---

Package brochures are public visitor-facing downloads, not an agent-only marketing asset. The brochure should use the package's hero image as its primary visual and include a QR link back to the current package detail page.

**Why:** Visitors need a shareable version of the same package information shown on the detail page, including the visual identity of the hero artwork, without requiring authentication or a referral code.

**How to apply:** Keep the download action directly below package consultation in the booking sidebar. Generate it from the currently selected package/departure data and retain a graceful fallback if a remote hero image blocks browser image loading.
